# 第5章：HBase API 连接

## 一、实验目标

1. 掌握在 **IntelliJ IDEA ** 中创建 Maven 项目的步骤。
2. 学会在 Maven 中添加 **HBase 客户端依赖**。
3. 熟悉 **HBase Java API** 的使用，包括：
   - 建立连接
4. 理解 HBase 的连接原理。

------

## 二、启动集群

| 软件      | 版本要求                          |
| --------- | --------------------------------- |
| 操作系统  | Windows 10                        |
| Java      | JDK 1.8                           |
| 开发工具  | IntelliJ IDEA  Finalshell  VMware |
| HBase     | 2.4.11                            |
| Hadoop    | 3.3.4                             |
| ZooKeeper | 3.8.3                             |

打开三台虚拟机，在 hbase1上 启动集群

```shell
myhbase.sh start
```

> [!NOTE]
>
> ⚠️ **提示**：在运行 Java 客户端前，必须确保：
>
> - Hadoop ,Zookeeper, HBase 已启动
> - HBase网页（192.168.175.130:16010）能正常进入

## 四、配置 HBase 依赖（pom.xml）

### 1. 打开 `pom.xml`

在根目录找到并打开 `pom.xml` 文件。

### 2. 添加 HBase 客户端依赖

在 `<dependencies>` 标签内加入以下内容：

```xml
<dependencies>
    <!-- HBase 客户端依赖，用于操作 HBase 数据表 -->
    <dependency>
        <groupId>org.apache.hbase</groupId>
        <artifactId>hbase-client</artifactId>
        <version>2.4.11</version>
    </dependency>
</dependencies>
```

### 1. 通过配置文件获取基础连接

这种方式依赖于HBase的默认配置文件来建立连接。

1. 新建配置文件

在 `src/main/resources` 下创建文件：

```
hbase-site.xml
```

2. 填写 HBase 连接配置：

文件内容复制服务器配置文件即可，位于 `/export/servers/hbase-2.4.11/conf/hbase-site.xml`

下面内容来自服务器配置文件，可直接复制粘贴。

```xml
<?xml version="1.0"?>
<?xml-stylesheet type="text/xsl" href="configuration.xsl"?>
<!--
/*
 * Licensed to the Apache Software Foundation (ASF) under one
 * or more contributor license agreements.  See the NOTICE file
 * distributed with this work for additional information
 * regarding copyright ownership.  The ASF licenses this file
 * to you under the Apache License, Version 2.0 (the
 * "License"); you may not use this file except in compliance
 * with the License.  You may obtain a copy of the License at
 *
 *     http://www.apache.org/licenses/LICENSE-2.0
 *
 * Unless required by applicable law or agreed to in writing, software
 * distributed under the License is distributed on an "AS IS" BASIS,
 * WITHOUT WARRANTIES OR CONDITIONS OF ANY KIND, either express or implied.
 * See the License for the specific language governing permissions and
 * limitations under the License.
 */
-->
<configuration>

    <property>
        <name>hbase.zookeeper.quorum</name>
        <value>hbase1,hbase2,hbase3</value>
    </property>

    <property>
        <name>hbase.rootdir</name>
        <value>hdfs://hbase1:8020/hbase</value>
    </property>

    <property>
        <name>hbase.cluster.distributed</name>
        <value>true</value>
    </property>

    <property>
        <name>hbase.wal.provider</name>
        <value>filesystem</value>
    </property>
</configuration>

```

**示例代码**:

在 `ConnectionUtil` 类中新增代码，下同：

```java
    // 1. 通过配置文件获取基础连接
    private static void configFileConnection() {
        Connection connection = null;
        try {
            connection = ConnectionFactory.createConnection();
            System.out.println("配置文件连接成功：" + connection);
            connection.close();
        } catch (IOException e) {
            System.out.println("HBase 连接获取失败！");
            throw new RuntimeException(e);
        }

    }
```
